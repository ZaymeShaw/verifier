# 拿出去的内容及去向

只分两类：**方案** → `spec/`（怎么做、怎么判、怎么拆、结构）；**实施** → `spec/implementation/` 或评测集 / report（代码现状、具体样本、运行数据、部署、文档改动经过）。
"需求"表示内容留在需求，但位置变了，本份只引用。
