> 7. **没有，要看手里是不是全集。** 问"有没有、是不是其中之一、共几个、全部"的事实，依据是那个范围的全部内容：能证明拿到的就是这个范围的全部（这次读全了，并且这个信息源对这个范围是全的），里面没有就是不是这样，是有矛盾，不是查不到；对象本身不存在是全集为空的特例。证明不了是全集——没读全、信息源可能漏、或手里的只是别的范围的全部（一条记录读全了，不等于关于它的一切都在里面）——没查到不等于没有，是查不到。（2026-10-27 用户定）
