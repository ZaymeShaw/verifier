# 真实轴"有没有 / 共几个"判法评测：用例清单（待用户过目）

**测什么**：只重放真实轴判定这一步。取证结果冻结为 10-28 记录里的原文（判官当时看到的那份），判官看完交判定；被测变量只有真实轴说明。
**判分**：① 结论与标准答案一致；② 标准答案是"凭全集判"的（共几个、全集里没有某项），依据里必须引了全集那段原文（返回里的"读取 N 条、去重为 N 张"/ total）。
**每个重放点跑 3 次**。

标准答案按"判官手里这份证据该判什么"标，不按现实真相标：手里没有全集，就是查不到。
