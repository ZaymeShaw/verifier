## 第1轮
用户：我不确定“安有护-国际版”是保险产品还是服务，先确认一下，再查怎么使用和一般理赔报案有什么区别。

业务回答：
**关于"安有护-国际版"的归属确认**

"安有护-国际版"（词典收录名"安有护国际"）属于**服务（健康管理增值服务）**，不是保险产品。它是平安为客户提供的一项重疾健康管理服务，覆盖从疑似确诊到康复的全流程就医协助。

**如何使用**

服务入口有两种路径：
1. **平安金管家APP首页 → 安有护**，扫描二维码直达服务入口；
2. **平安金管家APP首页 → 我的 → 权益中心 → 安有护**。

**达标门槛与时限**：
- 购买指定产品组合且**年交保费10,000元及以上**可享安有护国际版（年交保费3,000元及以上可享安有护基础服务）；
- 生效时间：对应保险合同过犹豫期后次日零时起即可使用；
- 权益人：对应保险合同的**被保险人**；服务期限同缴费期；
- 若保险合同解除或责任终止，服务相应终止（因给付重疾保险金导致责任终止的，自理赔结案之日起继续提供一年服务）。

**主要服务内容**（国际版）涵盖：在线问诊、音视频问诊、门诊预约协助及陪诊、检查安排协助、专家会诊、国内住院安排协助、手术安排协助、住院照护、出院安排协助、康复门诊/住院协助、上门护理、海外重疾住院安排协助（覆盖五大洲35个国家1300+家海外医疗机构）、重疾专案管理、心理咨询等。服务覆盖范围以服务预约时页面展示为准。

**与一般保险理赔报案的区别**

- **一般理赔报案**是保险事故发生后，按合同约定办理赔款给付的**理赔流程**，步骤为：报案 → 提交材料 → 材料审核 → 赔付协议达成。理赔结果以保险公司核定为准，主要涉及理赔金的给付。
- **安有护**是合同附带的**健康管理服务**，不涉及理赔金给付，而是提供就医协助与安排（挂号、陪诊、住院、手术、康复、海外就医等）和重疾专案管理，属于"用服务"而非"赔钱"。当发生保险事故需要理赔时，按理赔流程办理；同时符合条件时，安有护的就医服务可同步使用，两者是不同性质的工作，不存在相互替代。

"是否已享有该服务"需结合具体客户的合同和资格条件核定，此处未确认。
