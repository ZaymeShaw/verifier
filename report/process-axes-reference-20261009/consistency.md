# 条目级一致性：同一方法写两遍 / 手写 vs 盲写

「等价」有两种口径：**严格**=核对运行记录会得到同样结论（下限）；**宽松**=核对时盯着同一件事，允许一条更概括（上限）。配对由模型做（deepseek-flash），未人工复核全部，只抽查过一个轴，发现严格口径偏严。

| 比较 | 口径 | 左边被右边覆盖 | 右边被左边覆盖 |
|---|---|---|---|
| B1 vs B2 | 严格 | B1：96/248 = 39% | B2：97/245 = 40% |
| A vs B1 | 严格 | A：17/68 = 25% | B1：17/248 = 7% |
| A vs B2 | 严格 | A：19/68 = 28% | B2：23/245 = 9% |
| B1 vs B2 | 宽松 | B1：232/248 = 94% | B2：233/245 = 95% |
| A vs B1 | 宽松 | A：63/68 = 93% | B1：148/248 = 60% |
| A vs B2 | 宽松 | A：62/68 = 91% | B2：173/245 = 71% |
